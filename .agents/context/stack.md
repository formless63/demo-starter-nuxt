# Stack

Exact versions are pinned in `package.json` and `bun.lock`; key versions are Nuxt 4.5.2, Vue 3.5.43, TypeScript 5.9.3, Bun 1.4.2, Node 24, Better Auth 1.7.6, Drizzle ORM 0.45.3, PostgreSQL 18, Tailwind CSS 4.3.3, Reka UI 2.10.5, Tabler Icons 3.48.0, Vitest 5.0.1, and Playwright 1.63.0.

Nuxt/Nitro provides routing, SSR, server routes, runtime configuration, and portable Node output. Better Auth provides database sessions and OAuth; Drizzle/postgres provide typed SQL; Tailwind provides styling, Reka UI is the shadcn-vue primitive foundation, vue-sonner supplies toasts, and color-mode supplies SSR-safe theming. The runtime image uses supported Nitro Node output rather than Bun-specific APIs.

Official Nuxt documentation should be the primary source. Agents supporting MCP can connect to Nuxt's credential-free official endpoint `https://mcp.nuxt.com/mcp`; it is intentionally documented rather than committed as personal editor configuration. MCP is development-only and has no runtime role.
